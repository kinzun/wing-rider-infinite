# 云上奇行 · Wing Rider

桌面端 Three.js 无限骑行与蜂群战斗游戏。直接打开根目录 `index.html`，不需要服务器或网络素材。

## 开发入口

```sh
npm run build   # 源码 → 离线 index.html
npm test        # 先构建，再执行全部回归测试
npm run serve   # 可选，本地 HTTP 预览
```

运行和构建无需安装 npm 依赖；需要 Node.js 与 Python 3。源码格式使用 Prettier 3.6.2，可执行：

```sh
npm exec --yes --package=prettier@3.6.2 -- prettier --write src tests scripts package.json
```

第一次使用格式化命令需要联网获取开发工具；游戏运行不依赖它。

## 目录与职责

| 目录 / 文件            | 职责                                                                                              |
| ---------------------- | ------------------------------------------------------------------------------------------------- |
| `src/app.js`           | 创建模块、游戏生命周期、事件转发、帧循环、诊断入口                                                |
| `src/simulation/`      | WFC 地图、角色运动、技能命中、母舰与蜂群战斗；不依赖 DOM / Three.js                               |
| `src/render/`          | 模型创建、海天环境、角色动画、道路与舰队实例化渲染                                                |
| `src/effects/`         | 大招适配、粒子、爆炸和镜头震动                                                                    |
| `src/audio/audio.js`   | 程序合成音色、分层配乐、声部预算与回收                                                            |
| `src/ui/`              | 键盘输入、HUD、HTML 模板及 CSS                                                                    |
| `vendor/`              | Three.js、复制的原始六技能代码及许可                                                              |
| `scripts/`             | 构建、显式脚本依赖顺序、测试运行器                                                                |
| `tests/`               | 地图、战斗、技能、模型、音频及资源池回归测试                                                      |
| `build/`               | 自动生成的六技能 bundle，不手工编辑                                                               |
| `index.html`           | 自动生成的离线交付页面，不手工编辑                                                                |
| `docs/`                | [维护边界](docs/ARCHITECTURE.md)、[参考来源](docs/REFERENCES.md)、[历史升级记录](docs/HISTORY.md) |
| `review/` / `archive/` | 验证报告与截图 / 历史页面                                                                         |

新增模块时，将脚本加入 `scripts/browser-scripts.json`，保持依赖在调用者之前；不要直接改生成后的 HTML。详细数据流与改动入口见 [ARCHITECTURE.md](docs/ARCHITECTURE.md)。

## 操作

Enter 开始；WASD 骑行；Shift 冲刺；空格跳跃；Z 按住肩炮；C 熊吼；M 静音；P 暂停；Backspace 重试。

Q 冰刺、E 雷暴、R 陨石、F 光束、V 束缚场、X 冰川。1/2 飞机、3 筋斗云、4 鹈鹕：有效期间不会坠落，跌出赛道后 5 秒内可用就绪技能救回。

耐久 100；技能击中敌人恢复耐久。1024 架蜂群轮番围攻，母舰交替释放弹幕墙与横扫主炮。首次开始启用程序合成配乐和音效。

## 重装敌人与受击反馈

- 母舰耐久 900；12 架近景护卫中有 4 架重装（耐久 90、2.5 倍模型尺度），其余耐久 12。重装不会按原 32 秒规则自动退场；连爆只对普通护卫造成有限伤害，不能整队秒杀。
- 连续命中积累冲击，达到阈值进入 2.2 秒失衡，暂停攻击并承受 1.75 倍伤害；母舰的范围攻击也会被打断。血条下方青色条显示冲击积累。
- 受击闪白、后坐、命中火花和金属音；每损失 25% 耐久破一层装甲。母舰 48 块装甲按阶段脱落，重装护卫三块装甲逐步掉落，破甲附带碎片与音效。
- 蜂群扩大为 1024 架、16 个分层小队，使用一次合并的飞翼、机身、双发动机与尾翼几何。蜂群与弹幕均使用固定的批量绘制对象；弹幕仍固定 384 槽。
- Z 肩炮发射间隔 .18 秒，每秒补弹 2.8 发；弹药与弹体仍各限 8。

## 技能命中冲击

六招沿用参考工程的原生爆炸与冲击波，并增强爆心、粒子、六段延迟殉爆。镜头使用迁入的三轴震动与滚转，保留各技能的频率和衰减；命中时追加短促视角冲击。开始面板的“减少镜头晃动”仍能关闭震动、滚转、屏幕闪光与视角冲击。

最新浏览器样本与画面见 `review/impact-browser-report.json`、`review/impact-upgrade.png`。

## 性能边界

地图固定 12 槽；蜂群固定 1024 架；蜂群/母舰新增弹幕固定 384 槽；原导弹与肩炮各 8 槽。完整六技能视觉主体最多同时两个，音频最多 32 声部。池满时复用或跳过新效果，不累计地图或战斗历史。

测试覆盖 1000 波对象复用、技能生命周期、命中/吸血、飞行救援、暂停/重置与音频释放。浏览器短测不能替代多小时、跨显卡及实际音箱校准。

## 来弹辨识与声音

敌方弹幕改为沿速度方向的细长亮芯、橙红辉光与渐隐尾迹；母舰弹使用玫红色。辉光和尾迹共增加两次批量绘制，384 槽复用，不为每颗弹创建新对象。齐射声至少间隔 0.14 秒，擦身声至少间隔 0.2 秒，仍共用 32 声部上限。

Q/E/V 更擅长积累姿态压力，R/F 可留到失衡窗口爆发；母舰 HUD 显示姿态条与剩余窗口，临近碰撞的来弹显示方向提示。

本轮浏览器记录：`review/projectile-report.json`，截图：`review/projectile-refined.png`。1440×900 短测中弹幕占满 384 槽，帧间隔中位数 16.7ms、P95 17.6ms；这不是跨设备性能保证。
