# 云上奇行：CHAOS STACK

飞机 × 北极熊肩炮 × 悟空筋斗云。基于上一版无限骑行继续改造，复用 Three.js 场景、角色、WFC、对象池、合成音乐和输入框架。离线打开 index.html 即可玩；不需要安装依赖或请求网络素材。

## 蜂群围攻 / 全键盘 / 战斗音频（当前版本）

- **Enter 开始、WASD 骑行、Z 按住肩炮、Q/E/R/F/V/X 六招、1/2/3/4 飞行、C 熊吼、M 总静音、P 暂停、Backspace 重试**。不需要操作鼠标。
- 512 架无人机分成八队，左右包抄、俯冲、轮番瞄准发射。384 个共享弹幕槽，满池跳过新弹；死亡机体立即停止发射。弹体使用逐帧扫掠碰撞，命中扣 1 耐久，与原有 0.7 秒受击保护共用。
- 六招按三维覆盖范围击毁蜂群，不再按编号移除；冰刺、雷暴、陨石、束缚场、冰川使用不同范围，光束是前方长廊。熊吼、鹈鹕和筋斗云也可清理近身机群/弹幕，Z 肩炮会锁定存活无人机。每架无人机恢复 .25 耐久，满血封顶。
- 母舰交替使用 **1.8 秒预警 → 弹幕墙（绿色缺口）** 和 **1.8 秒预警 → 横扫主炮（左向右扫射）**。主炮实际命中范围与可见光柱一致，筋斗云和护盾能挡伤害；母舰死亡取消未完成扫射。半血缩短两次大招之间的间隔。
- 每架死亡无人机都有独立扩张火球，512 个实例化槽复用；重粒子爆炸每帧最多四处，弹幕、机体和死亡火球各自批量绘制。不创建 512 个灯光或物理刚体。
- 首次按 Enter/开始自动解锁声音。20 个程序合成音色缓冲：六招的蓄能/释放/命中、爆炸低频、熊吼、云气、掠过声、肩炮、警报及鼓/贝斯/琶音。背景音乐随巡航、蜂群、母舰、主炮开火分层变化；命中瞬间短暂压低音乐。镜头震动和声音由相同战斗事件触发。
- 音频总线含动态压缩；最多 32 个同时声部，结束断开节点，缓冲只创建一次。暂停清空声音，静音后不调度新声部，重开声音复用缓冲。所有音乐与音效为原创合成，没有外部音频下载。
- `check-siege.cjs` 覆盖真实命中、护盾、范围清敌、母舰预警/安全缺口、1000 波对象身份与渲染缓冲复用；`check-audio.cjs` 验证非静音有限采样、声部上限及释放。浏览器实测全键盘射击、实际非零音频输出、M 静音和 P 暂停。
- 当前机器 1440×900 无头 Chrome 战斗短测中位约 16.7 ms / P95 17.5 ms，非跨设备保证；最新报告位于 `review/siege-browser-report.json`。未做多小时、跨显卡或音箱听感校准。

## 操作与技能

| 按键 | 效果 |
|---|---|
| A / D | 地面转向；动力模式中可小幅修正自动引导 |
| W / Shift | 骑行加速 / 能量冲刺，冲刺目标 209 km/h |
| S | 减速 |
| 空格 | 起跳，不会按住自动连跳 |
| 1 | 飞机一级推进：270 km/h，3.2 秒，8 秒冷却 |
| 2 | 飞机四发超燃：396 km/h，3.8 秒，13 秒冷却 |
| 3 | 悟空筋斗云：540 km/h，无敌护航 4.5 秒，20 秒冷却 |
| Z | 北极熊跟踪肩炮：优先拦截来袭导弹，其次击碎前方障碍 |
| C | 熊吼：清除来袭导弹并产生 1.6 秒护盾，8 秒冷却 |
| P / Esc / Backspace | 暂停 / 暂停 / 重试 |

技能按钮也可用鼠标点击。速度为游戏单位换算，实际达到目标需要加速时间。三段动力不能同时启动；冷却从启动计时。动力结束会限速并辅助降落，尚未结算的坠落也可用就绪的动力技能救场。

弹药上限 8，每秒补充 0.7；无目标不扣弹，已被一发肩炮锁定的目标不会重复分配。每个角色技能有实际模型、特效、冷却和游戏效果。

## 危险与反击

- WFC 窄桥、变线、移动障碍和横栏。金色跳板自动弹起，也可手动起跳。
- 导弹先锁定 1.4 秒，最后 0.45 秒固定目标位置，然后发射。横移、起跳、肩炮、熊吼、筋斗云都是应对方式。
- 超过 300 米开始三发齐射，后续来袭间隔逐步缩短到 2.5 秒。
- 险穿、拦截和躲弹带来连击、得分、能量奖励；受击中断连击。耐久耗尽或超过 5 秒未获救的坠落结束。
- 首次开始默认开启声音；M 总静音，背景音乐和技能音由 Web Audio 实时生成。无商业音频素材。
- “减少镜头晃动”关闭速度变焦、镜头晃动和冲刺边缘效果，不影响技能。

## 不从零做玩法

见 [研究来源与采用机制](REFERENCES.md)。主要借鉴 Sonic 的载具变形/角色大招，Mario Kart 的追踪攻击、自动突进和范围清弹，Distance 的赛车跳跃与飞行，Thumper 的连续成功与压力反馈。使用本项目已有引擎与资源池，不复制这些游戏的代码、模型、音频或关卡。

## WFC 与固定资源

world.cjs 使用一维道路瓦片 WFC：候选集合、加权 Shannon 熵、按权重坍缩、双向约束传播。入口/出口位置和宽度一致；限制连续高风险段，每批保证绕障段。12 格一批，最多重试 8 次，失败用安全直道兜底。使用种子保持确定性。

- 固定 12 个地图槽：身后 2 段、当前段、前方 9 段；仅缓存 12 个瓦片。
- 固定 8 个敌方导弹、8 个肩炮弹和 180 个粒子。模型一次创建，结束后复用。
- 路面顶点缓冲区原地更新；共用几何与材质。不保存地图历史。
- 每 64 米重置局部坐标，相机和粒子同步平移。
- WFC 当前为固定小批次同步计算；扩大规模时再考虑 Worker。

这是街机近似物理和单条无限路线，不是完整开放世界或真实飞行模拟。

## 限制

没有数小时真实运行、跨硬件或精确操作系统内存/显存字节测试。固定对象池不会随距离累积，但运行时分配和垃圾回收仍会让内存波动。刺激感是玩法目标，不承诺任何人的生理心率变化。未制作商业级模型、联网对战、手机适配或视频。
